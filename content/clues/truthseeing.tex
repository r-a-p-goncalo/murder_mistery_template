\ClueSheet{clue:truthseeing}{Truth seeing artifact}{

\paragraph{What it is}

An artifact of \Character{prevlover}, which allows, once a day, to discern if a written statement is truth or false.

\paragraph{How can it be found / solved}

It has two riddles locking it:
\begin{itemize}
    \item What allows you to see as if you were there? Answer: Binoculars. Note that this riddle is hard because the players can touch and feel the object in question. 
    \item What is 1 + 1 = 2? What is 1 + 1 = 3? Answer: A truth and a lie.
\end{itemize}

\paragraph{What it reveals}

It indirectly reveals that \Character{prevlover} was in \Character{usurper}'s study, if the players already know that the clues are from \Character{usurper}'s study.
