

\ClueSheet{missingmusic}{Coleção de música}{

\paragraph{O que é}

Uma coleção de discos de música:
\begin{itemize}

    \item Dias banais (Lume azul). Sem "Atiras pedras ficas a pensar". Isto aponta para as pedras.
    
    \item Feliz com alguém (Lume azul). Sem "Não te preocupes se doer". Esta é a palavra-passe das pedras.

\end{itemize}


\paragraph{O que revela}

Serve apenas para dar uma indicação de como resolver a pista \Clue{rocks}.
