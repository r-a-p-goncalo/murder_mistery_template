\subsection{Theme and tone}
This is a starting point for a party in which there is a main mystery to be solved by the players. Each character has an agenda. Adjust the premise, evidence, and player count before distributing character sheets.

\subsection{Host checklist}
\begin{itemize}
  \item Prepare one character sheet for each player and keep the GM material private.
  \item Place physical versions of the clues in their intended spaces.
  \item Decide the food, music, decorations, safety boundaries, and the moment that begins the main mystery.
  \item Choose how long investigation and final accusations will last.
\end{itemize}
